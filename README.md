# InventoryScript

InventoryScript is a Windows C++ utility tool that pulls system information and compiles that data into a text file.

## Information Collected
- Computer name
- CPU information
- RAM information
- Storage information
- GPU information
- Operating system information
- IP address
- MAC address

## Requirements
- Windows
- C++17 or newer
- Microsoft Visual C++ compiler

## Compilation
```cmd
cl /EHsc /std:c++17 InventoryScript.cpp
